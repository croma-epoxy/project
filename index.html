Guía de implementación ✳

Del sensor al dashboard: prepara tu stack de monitoreo edge.

RASPBERRY PI 4 B
⌘

Arquitectura de referencia

Sensores RS485 → conversor USB-RS485 → Raspberry Pi → Python → Supabase → dashboard.

SENSORES→RS485→RASPBERRY PI→SUPABASE
ⓘ

Importante: las direcciones Modbus, baud rate, paridad y registros dependen del modelo de sensor. Revisa su manual antes de energizar o escribir registros. Nunca expongas claves secretas de Supabase en el frontend.
